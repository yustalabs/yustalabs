# Nicolás Yusta

Full-stack developer in Buenos Aires (UTC−3). I build custom management systems for businesses that still run on spreadsheets and paper.
Four are in production, used daily by their owners. I work alone, end to end.

## Systems in production

- **MATIAL** · road-signage workshop · Buenos Aires. 136 quotes and 113 delivery notes on its own database, and a second contract signed 72 days after the first. [Case study](https://yustalabs.com/en/work/matial)
- **Oro Gym** · gym · Buenos Aires. 232 members and 401 payments, each recorded under the name of whoever took it. [Case study](https://yustalabs.com/en/work/oro-gym)
- **SLE Mensajería** · courier company · Buenos Aires. 1,656 deliveries tracked across 3,680 documents. [Case study](https://yustalabs.com/en/work/sle-mensajeria)
- **Daily-installment lender** · small loans · Mendoza. 13,052 payments recorded across 20,218 documents. [Case study](https://yustalabs.com/en/work/daily-installment-lender)

The code of these four belongs to the clients and stays private. The public repositories here are sector demos that run in the browser with sample data.

## Yusta HQ

The system I run my own company with: 17 agents on Anthropic and Gemini models that find prospects, send sales emails within daily caps, produce content and check the client apps.
Node 24 with the standard library only, zero npm dependencies, 2,086 automated tests. [Case study](https://yustalabs.com/en/work/yusta-hq)
